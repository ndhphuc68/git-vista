Why GitVista?

Designed for Clarity, Speed, and Peace of Mind

Powerful desktop tools crafted to streamline everyday development without intimidating Git intricacies.

🌳

Interactive Commit Graph

Crystal-clear topology-based branch visualization. Virtualized rendering effortlessly handles tens of thousands of commits with 0ms lag.

🔀

Visual Interactive Rebase

Drag-and-drop commit reordering with full Pick, Reword, Squash, Fixup, and Drop support. Includes live timeline preview and auto-stash.

🛡️

10s Instant Undo & Safety Refs

Never fear losing work. Risky actions automatically create safety backup refs, and an interactive 10-second countdown toast lets you reverse mistakes in one click.

📑

Multi-Tab & Multi-Repo Workspace

Open and inspect multiple repositories side-by-side in a single window with partitioned cache and instant zero-latency tab switching.

🔍

Word-Level Diff & File Inspector

Character and word-level difference highlighting with whitespace ignore toggle, alongside a slide-over drawer featuring line-by-line Git Blame and file history.

⚔️

3-Way Conflict Resolver & PR Hub

Resolve merge conflicts visually with Ours vs Theirs vs Result hunks. Connect directly with GitHub to browse, inspect, and checkout Pull Requests.

Efficiency First

Keyboard-Driven Navigation

Designed from the ground up so you rarely have to take your hands off the keyboard.

Ctrl + K

Open Command Palette (search commands & branches)

Ctrl + T

Open a new repository tab

Ctrl + W

Close the active repository tab

Ctrl + Tab

Switch to next / previous repository tab

Ctrl + 1..9

Jump directly to tab index 1 through 9

Ctrl + B

Toggle branch sidebar visibility

Ctrl + /

Quickly focus search and filter input

Escape

Close active dialog, modal, or clear selection
